# Module 1 Workshop 1 

This Module01 is an introduction to R. Opening the program and beginning to understand the features and languages. 

In this module we had 4 workshops, starting from the basics i.e. how to use R as a simple calculator and common syntax errors. 

#### Workshop 1: Foundations  
- the importance of writing styles and which one I will use 
- the meaning of functions and arguments 
- packages and data types 
- data frames and tibbles 
- how to open and save new projects 

#### Workshop 2: Visualisations 

This workshop was all about visualisations aka, using all the data collected and making graphs and plots! This is an important part of science communication, being able to take large messy datasets and turn them into an easy-to-read, colourful visual (graph, plot). 
We used the package ggplot2 to create our vidualisations, changing colours and shapes and using different lines of data to create a more suitable graph to represent the data. 

#### Workshop 3: Reproducible Research 
This is when we set up out Git and GitHub (version control), so other people, including ourselves can reach our work from any computer anywhere in the world. 

#### Workshop 4: The Developer's Tool & Toolbox 
During our final workshop for module 1, we connected to our GitHub Copilot (AI) and installed the chattr package which are both modern AI-assisted tools.  
We also learnt which circumstances to use a function in the tidyverse package, if_else, when we are needing to check a single true/false condition, and case_when, which is used when we need to evaluate multiple conditions and return different results. 
And finally, for_loops, for repeating code chunks.
